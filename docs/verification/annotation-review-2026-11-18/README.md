# 주석 다시 읽기

| 배치 후보 | 사용 흐름 |
|---|---|
| 기존 메뉴에 배치 · 적용 | 사이드바 주석 목록에서 검색과 색 선택을 함께 사용한다. 발췌는 내보내기에서 복사하고 영상 반복은 각 시점 메모에서 시작한다. |
| 독립된 복습 화면 | 서재에서 문서별 복습 화면을 열고, 상단 색 필터와 발췌 도구 아래에 문장과 영상을 한 목록으로 표시한다. 휴대폰에서는 본문과 목록 사이를 전환한다. |

적용한 안은 사용자가 이미 열어 둔 문서에서 바로 검색하고 복사할 수 있다. 발췌 버튼은 접힌 종이 위에 인용 부호를 그렸으며 기존 테마의 글자색을 따른다. 기본 슬레이트와 두 장의 카드를 겹친 청록색 대안을 그림에서 비교할 수 있다. [아이콘·색상 후보](design-options.svg)
