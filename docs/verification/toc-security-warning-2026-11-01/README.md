# 목차 안 보안 경고색 검증

LibreMemo 1.7.3 준비본에서 목차 안의 악성코드 경고를 붉은 배경·흰 글자·밝은 붉은 테두리로 표시한다.

로컬 단위 871개, JavaScript·JSON 문법 207개, 빌드·diff 검사를 통과했다. 경고의 중첩 텍스트와 줄바꿈, 동적 해제·추가, 원래 링크 이벤트와 노드 유지, 본문 제외, 내보내기 정리를 확인했다.

`codememo-browser`로 실제 컴파일된 앱 CSS를 사용하는 정적 목차 미리보기의 390px 밝게·어둡게 화면을 확인했다. 두 실행은 HTTP 200·오류 없음이었고 화면을 직접 검토했다. [밝게](preview-light-390.png), [어둡게](preview-dark-390.png), [어두운 화면 실행 결과](preview-dark-result.json)를 보관한다. 이 정적 미리보기는 전체 앱의 가져오기·원래 문서 스크립트 실행 검증과 구분한다. 임시 검증 서버는 종료했다.

전체 앱의 원래 목차·일반 목차·테마·휴대폰과 동적 변경, GitHub Pages 게시·공개 Chrome 검증 결과는 완료 후 여기에 보충한다. 현재 게시 완료를 뜻하지 않는다.
