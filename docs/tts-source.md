# MemoSuite TTS 이식 원본

- 독립 HTML 브라우저 엔진: `packages/shared/src/components/readAloudRuntime.ts`
- 한국어 문구: `packages/shared/src/i18n/locales/ko.ts`
- 원본 날짜: 2026-10-14

툴바와 패널의 스타일 선언·버튼 순서·아이콘을 MemoReadAloud에서 가져왔습니다. TTS 버튼은 재생하지 않고 툴바만 열고 닫습니다. 문장 분할, 수식 발음, 음성 필터, 문장 이동, 일시정지·재개는 독립 HTML 런타임을 바탕으로 합니다. LibreMemo의 iframe 확대·스크롤 좌표, 문서 수명, 전체 화면, 파일 배포 구조와 재개 위치 처리에 맞춰 조정했습니다. 서버 API가 없는 GitHub Pages에서는 브라우저 음성을 사용하며 MemoSuite의 서버/Piper/복제 음성을 사용할 수 있다고 표시하지 않습니다.

가져오는 HTML에는 TTS 기능이 없다는 전제로, 상단 TTS 버튼과 낭독 툴바는 LibreMemo가 제공합니다. 책 안의 TTS 버튼을 탐지하거나 기존 재생 이벤트를 가로채는 호환 코드는 사용하지 않습니다. 상단 TTS 버튼으로 연 일반 본문 읽기는 툴바의 ▶ 버튼을 눌러야 시작하며, HTML 내보내기에는 앱의 읽기 버튼이나 음성 기능을 삽입하지 않습니다.

텍스트 선택 메뉴의 읽어주기도 같은 낭독 플레이어와 음성·언어·속도 설정을 사용합니다. 선택 메뉴의 읽어주기를 누르면 선택 범위 모드로 열고 **곧바로 재생**합니다. 플레이어가 이미 열려 있으면 같은 플레이어에서 이전 재생을 중단하고 새 선택을 읽습니다. 선택 시작과 끝 사이만 읽고 멈추며 문장 이동·일시정지·재시도·정지도 그 범위를 유지합니다. 텍스트를 선택하는 것만으로는 재생하지 않습니다. 스크롤하거나 다른 글을 선택해도 범위를 자동으로 넓히지 않으며, 새 범위는 다시 선택 메뉴의 읽어주기로 지정합니다. 플레이어를 닫고 상단 스피커로 다시 열면 일반 본문 읽기로 돌아갑니다. 선택한 글이나 장이 바뀌면 다른 내용으로 대체해 읽지 않고 다시 선택하라는 안내를 표시합니다. 별도 발화 코드 없이 공통 엔진을 사용자 클릭 안에서 즉시 호출하며, 음성 오류·시작 응답 누락은 같은 범위에서 ▶로 재시도할 수 있도록 표시합니다.

LibreMemo의 상단 진입 버튼은 기존 스피커 아이콘을 사용하며 책의 A− 버튼 바로 왼쪽에 배치합니다. 낭독 툴바는 높이 20px의 컴팩트한 형태로 조정했으며 원본의 재생 조작 순서와 설정 패널·음성 엔진은 유지합니다.

플레이어·설정창 UI 스타일은 `public/design.tailwind.css`에서 앱 공통 테마와 함께 컴파일해 `public/styles.css`로 제공합니다. JavaScript에서 별도 플레이어 CSS를 주입하지 않습니다. 언어·음성 목록과 버튼은 밝게/어둡게 테마의 청회색 강조를 사용하며, 문장 하이라이트는 문서의 격리된 표시 영역에서 관리합니다.

일시정지 후 스크롤하거나 다른 장으로 이동하면 다음 ▶는 새 화면의 최상단에 보이는 첫 줄부터 시작합니다. 현재 읽고 있는 줄이 화면 안에 보이는 동안에는 사용자가 이동해 둔 스크롤 위치를 그대로 존중해 강제로 화면을 움직이지 않으며, 읽는 줄이 화면 밖으로 벗어날 때만 따라 이동합니다. 일시정지 중 문장을 클릭·선택하면 자동 재생하지 않고 다음 시작 문장으로 잡으며, 그 뒤 다시 스크롤하면 현재 화면 위치를 우선합니다. 위치와 본문이 그대로면 멈춘 문장을 다시 읽습니다. 재개 시 현재 불러온 본문의 읽기 인덱스를 새로 준비해 이전 장의 텍스트나 DOM 위치를 재사용하지 않습니다. 이 조정은 LibreMemo 내부에만 적용하며 이식 원본이나 가져온 HTML 파일을 변경하지 않습니다.

재생 제어는 실행 중인 문장과 발화를 함께 확인해 이전 문장의 중복·지연 종료/오류를 무시합니다. 재생 취소 전에 현재 발화와 시작 감지를 무효화하고, ▶에서는 브라우저 음성 엔진에 남은 일시정지를 먼저 해제합니다. `cancel()`과 `speak()`가 엔진의 일시정지 상태를 바꾸지 않는 것은 [Web Speech API 규약](https://webaudio.github.io/web-speech-api/#tts-methods)에 따릅니다. 실제 발화의 시작·종료·오류를 반영하고, 오류가 나거나 8초 동안 시작 응답이 없으면 같은 문장에서 재시도할 수 있는 일시정지 상태와 안내를 표시합니다. 자동으로 문장을 건너뛰거나 오류를 반복 재시도하지 않습니다. 닫기·정지·문서 전환 때 감지 타이머를 정리하며, UI·음성·속도 선택과 원본 파일은 바꾸지 않습니다.
